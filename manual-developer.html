Tab 1

JSON Formatter

Formats messy JSON into a clean, readable, indented structure — or minifies it down to a single compact line — and checks it's valid along the way.

  1. Paste your JSON into the input box.
  2. Click "Format" to pretty-print it with indentation, or "Minify" to compress it onto one line.
  3. Check for errors. If your JSON isn't valid, an error message points to roughly where the problem is, rather than just failing silently.
  4. Copy the result using the copy button.
Good to know: A common cause of "invalid JSON" errors is a trailing comma after the last item in an object or array — valid in JavaScript object literals, but not valid in strict JSON.

Tab 2

Base64 Encode/Decode

Converts text to and from Base64 encoding, correctly handling non-Latin text and emoji.

  1. Choose "Encode" or "Decode" using the mode toggle.
  2. Paste your text into the input box (plain text to encode, or a Base64 string to decode).
  3. Read the result in the output box, which updates live.
  4. Copy the result using the copy button.
Good to know: Some simpler Base64 tools break on non-English text or emoji because of how they handle character encoding — this one is built specifically to handle UTF-8 text correctly, so Korean, Japanese, emoji, and other non-Latin characters round-trip correctly through encode and decode.

Tab 3

UUID Generator

Generates random v4 UUIDs (universally unique identifiers), one at a time or in a batch.

  1. Choose how many you need — a single one, or a batch (enter the quantity).
  2. Click "Generate."
  3. Copy the result(s) using the copy button — a batch is typically copyable as one list, one UUID per line.
Good to know: Each UUID is generated independently using a cryptographically random source, so even generating thousands in a batch carries no meaningful risk of a duplicate.

Tab 4

Color Converter

Converts a color between HEX, RGB, and HSL formats, with a live preview swatch.

  1. Enter a color in any one of the three formats (HEX, RGB, or HSL) — or use the color picker if one is provided.
  2. Read the converted values in the other two formats, updated live.
  3. Check the swatch to confirm it's the color you meant.
Good to know: HEX codes can be typed with or without the leading "#" — the tool accepts either.

Tab 5

URL Encode/Decode

Percent-encodes text for safe use in a URL, or decodes an already-encoded URL back to readable text.

  1. Choose "Encode" or "Decode."
  2. Paste your text or URL into the input box.
  3. Read the result, updated live.
  4. Copy the result using the copy button.
Good to know: This is most often needed for putting special characters (spaces, &, ?, #) safely into a query string parameter — encode just that parameter's value, not the whole URL, or you'll end up encoding the slashes and colons that need to stay as-is.

Tab 6

Dummy Data Generator

Generates fake but realistic-looking test data — names, emails, phone numbers, addresses — for testing an app or filling in a demo.

  1. Choose which fields you need (name, email, phone, address, etc.) using the checkboxes.
  2. Choose how many rows of data to generate.
  3. Choose your output format — CSV or JSON.
  4. Click "Generate."
  5. Copy or download the result.
Good to know: Every value is randomly generated and entirely fictional — none of it corresponds to a real person, email address, or phone number, so it's safe to use freely in test environments, demos, or sample datasets.
