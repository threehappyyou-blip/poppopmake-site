Tab 1

Invoice Generator

Creates a clean invoice as a downloadable PDF, ready to send to a client.

  1. Open the tool. Go to Business Tools and make sure "Invoice Generator" is selected (it's the first tab).
  2. Fill in the From / To details. "Your name / business," "Your email," and (optionally) "Your address" go on the left; "Bill to," "Client email," and (optionally) "Client address" go on the right. Addresses can run over several lines.
  3. Fill in the invoice details. "Invoice #," "Date," and "Due date" are plain text boxes, so type them the way you want them to appear (the greyed examples show the idea, like INV-001 and 2026-08-24). Leave any of them empty and it simply won't be printed.
  4. Edit the line items. Two example lines are there to start with — change them or remove them with the × button on the right of each row. Click "+ Add line item" for each product or service, then fill in a description, a quantity, and a unit price. The line total appears automatically. The ↑ and ↓ buttons move a line up or down. Quantity and price can't go below zero.
  5. Add a discount or tax if you need to. "Discount (%)" (0 to 100) is taken off the subtotal first, and "Tax rate (%)" is then charged on the discounted amount. The box beside them shows Subtotal, Discount (only when there is one), Tax, and Total as you type, so you can check the numbers before downloading. All amounts are in US dollars ($).
  6. Add notes if you want them. Anything in "Notes (optional)" — payment terms, bank details, a thank-you — is printed at the bottom of the invoice, and the line breaks you type are kept.
  7. Click "Download Invoice PDF." The PDF downloads named after your invoice number (for example INV-001.pdf), or invoice.pdf if you left the number empty. A long invoice simply continues onto a second page.
Good to know: Nothing you enter is saved anywhere between visits — if you send invoices to the same clients regularly, keep a copy of the filled-in details somewhere on your own device so you're not retyping them every time. The invoice PDF uses a standard font, so English and Western European letters (é, ñ, ü), numbers, and symbols like € all work, but Korean, Chinese, Japanese, Arabic, Cyrillic, and emoji can't be drawn on it. If you type one, the tool tells you which box and which character is the problem so you can write that part in Latin letters and try again.

Tab 2

QR Code Generator

Turns a link or text into a scannable QR code, with your own colors, downloadable as a PNG.

  1. Open the tool. Click the "QR Code Generator" tab.
  2. Type or paste your link or text into "Link or text." The code updates as you type — there's no separate "generate" button. The box can hold several lines, which is handy for a contact card or an address. If you clear it, the code goes away and a note asks you to type something (the tool never quietly makes a code for a different link).
  3. Customize the colors (optional). Click the colored squares under "Code color" and "Background" to pick new colors; the code you see updates immediately.
  4. Choose the size. "Size" sets the picture you download: 256, 512 (the default), or 1024 pixels square. The preview on screen stays the same size.
  5. Choose the error correction. Low gives the smallest, simplest code; High (the default) is the most resistant to smudges, scratches, or a logo placed over it, but makes the code denser. If your text is too long for the level you chose, the tool uses the next lower level automatically and tells you.
  6. Read the notes under the code. A message appears if the two colors are too close together, if the code is lighter than its background, or if there is so much text that the code gets very dense and needs a bigger size.
  7. Click "Download PNG." The code downloads as qr-code.png at the size you chose, with the blank border that scanners need already around it.
Good to know: Before printing a QR code anywhere permanent (business cards, signage), scan it yourself with your phone's camera first to confirm it goes to the right place — this matters most if you customized the colors. Dark code on a light background is the safest combination. A code can hold about 2,900 characters at Low error correction and about 1,270 at High, but shorter text makes an easier-to-scan code, so links and short messages work best. Korean and other non-English text, accented letters, and emoji scan back exactly as typed.
