내 폰에만 저장되는 무료 가계부

지출은 세 번 터치로 기록하고, 한 달 예산을 정하고, 포스트잇 메모와 일기도 한 곳에서. 회원가입도 은행 로그인도 없고 아무것도 업로드되지 않아요. 모든 기록은 암호화되어 나만 아는 비밀번호로 잠겨요.

핵심 요약
  • 무료, 회원가입 없음. 아이폰·안드로이드·윈도우·맥의 브라우저에서 바로 써요.
  • 기록은 내 기기에만 AES-256-GCM으로 암호화해서 저장돼요. 팝팝메이크도 볼 수 없고 복구할 수도 없어요.
  • 은행 연결 없이 직접 입력, 자주 쓰는 항목 버튼, 은행 CSV 가져오기로 기록해요.
  • 휴대폰을 바꾸면 암호화된 백업 파일 하나로 옮겨요.

다른 가계부 앱과 비교

내 데이터는 이렇게 보호돼요

내 기기에만 저장

쓰는 모든 내용은 휴대폰이나 컴퓨터의 브라우저 안에만 저장돼요. 이 앱에는 서버도 계정도 없어요. 앱 화면은 다른 사이트에 접속할 수 없도록 보안 설정이 되어 있고, 광고나 분석 코드도 없어요.

저장 전에 암호화

가계부 기록, 메모, 일기, 사진을 AES-256-GCM으로 암호화해요. 암호화 키는 비밀번호(PBKDF2-SHA-256, 60만 번 반복 처리)로 보호되고, 처음에 한 번 보여드리는 복구 코드로도 따로 보호돼요.

막을 수 없는 것

저희는 비밀번호를 재설정하거나 데이터를 복구해 드릴 수 없어요. 비밀번호를 아는 사람이나 기기에 설치된 악성 프로그램은 막을 수 없어요. 짧은 숫자 비밀번호는 약하니 더 긴 비밀번호를 쓰세요.

홈 화면에 설치하세요

설치하면 일반 앱처럼 한 번에 열리고, 인터넷 없이도 쓸 수 있고, 휴대폰이 데이터를 지울 가능성도 크게 줄어요.

사파리에서 poppopmake.com/vault 를 열고 공유 버튼을 누른 뒤 “홈 화면에 추가”를 누르세요.

크롬이나 엣지 주소창 오른쪽 끝의 설치 아이콘을 누르세요.

같은 앱 안에 함께 있어요

비밀번호 하나, 백업 파일 하나로 가계부, 포스트잇 메모, 일기를 모두 관리해요.

자주 묻는 질문

정말 무료인가요?

네. 회원가입, 구독, 유료 기능이 없어요. 이 사이트의 소개 페이지에는 광고가 있지만 앱 화면에는 광고가 없어요.

팝팝메이크가 내 지출 내역을 볼 수 있나요?

아니요. 기록은 암호화되어 내 기기의 브라우저 안에만 저장돼요. 앱에는 서버가 없고, 저희는 데이터도 비밀번호도 복구 코드도 받지 않아요.

비밀번호를 잊으면 어떻게 하나요?

처음 설정할 때 보관한 복구 코드로 새 비밀번호를 정할 수 있어요. 둘 다 잃으면 아무도 열 수 없으니 복구 코드와 백업 파일을 안전한 곳에 보관하세요.

휴대폰과 컴퓨터에서 같이 쓸 수 있나요?

쓸 수 있지만 자동으로 동기화되지는 않아요. 한쪽에서 백업 파일을 만들어 다른 쪽에서 복원하세요. 복원하면 그 기기의 내용이 백업 내용으로 바뀌어요.

은행이나 카드사와 연결되나요?

아니요. 직접 입력하거나, 자주 쓰는 항목 버튼을 누르거나, 은행에서 내려받은 CSV 파일을 가져오면 돼요. 파일은 내 기기 안에서만 읽어요.

알아두세요: 이 앱은 기록을 돕는 도구이며 재무·세무·법률·의료 조언을 제공하지 않아요. 데이터는 내 기기에만 있으니 백업 파일을 꼭 보관하세요. 저희는 데이터를 대신 복구해 드릴 수 없어요. 개인정보처리방침(영문), 이용약관(영문), 사용설명서(영문)도 참고하세요.
